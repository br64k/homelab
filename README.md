# homelab

## About

This repository contains documentation and related files for my personal homelab setup. It includes details about the hardware, software, and network configurations used to manage and maintain the homelab environment.

## Hardware

While rich AI kiddos can afford to buy a shitload of Mac Mini's, I'm a poor boy and have to make do with what I can afford. Here's a list of the hardware I've used in my homelab:

- 20 y.o. APC CS 500 with removed buzzer and custom made battery 
- GL.iNet GL-MT6000(Flint 2)
- NiPoGi AM21(R7 8745HS, 32Gb DDR5, 512Gb + 1TB NVMe SSD)
