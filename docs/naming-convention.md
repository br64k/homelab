# Naming convention

## About

I hate naming things. A long time ago, I used to name things using a custom hash function with the name as the input.

But those names weren't memorable and were a pain to type from a phone.

Later, I discovered a naming scheme (or convention, I don't know) used in the Docker project and created a similar one.

So this document describes the naming convention used for all my home resources.

## Convention

The convention is pretty damn simple. It uses a predefined in [scripts](https://github.com/br64k/scripts) list of adjectives and vegetables/fruits names.

Resulting name consists of two words separated by a dash: adjective-fruit/vegetable.

## Examples

For example:

- old-cabbage
- crisp-lemon
- clumsy-cherry
- etc.
