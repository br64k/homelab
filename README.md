# homelab

## About

This repository contains documentation and related files for my personal homelab setup.

It includes details about the hardware, software, and network configurations used to manage and maintain the homelab environment.

## Hardware

Here's a list of the hardware I've used in my homelab:

- UPS: APC CS 500 with removed buzzer and custom-made battery
- Router: GL.iNet GL-MT6000 (Flint 2)
- Server: NiPoGi AM21 (R7 8745HS, 32 GB DDR5, 512 GB + 1 TB NVMe SSD) running Proxmox
